# BBS KH2-Style

Makes *BBS*  play more like Kingdom Hearts II.
One mod, installed with the OpenKH Mod Manager.

## What it changes

- **Command menu**: Attack / Magic / Item / Link, as in KH2. Magic, Item and Link open a list of what is in
  your deck; after a command is used the cursor is back on Attack.
- **MP instead of reloads**: commands cost MP (their old reload time, so Fire 10, Firaga 15 ...). At 0 MP the
  bar recharges (MP charge). Cure takes all remaining MP. Ethers and Elixirs restore MP. KH2-style MP bar.
- **Command Styles and finishers are offers**: a full gauge shows a prompt with a timer above the menu. Press
  the style button (the game's old deck-command button) to take it; Attack stays Attack meanwhile.
- **Pace**: attacks, commands and items play 15 % faster; a tilted stick ends an action as soon as its last
  hit is over; after an aerial attack you fall instead of hanging; spells go off and unlock at KH2's times.
- **Camera**: KH2-style field and battle camera.
- **Revenge values**: humanoid bosses can no longer roll dice to escape on every hit. Each hit builds a hidden
  value (hit 1, magic 1.5, finisher 3, shotlock hit 0.3) and at the boss's limit he breaks out with his own
  counter. Vanitas, Vanitas Remnant, Eraqus, Armor of Eraqus, Braig, Mysterious Figure, Terra-Xehanort, the
  Ventus / Terra / Aqua bosses, Captain Hook, Maleficent, Experiment 221, Zack, Hades, Master Xehanort, and No
  Heart (who never flinches: his burst is tied to the value). Large bosses are untouched.

## Requirements

- Steam version of KINGDOM HEARTS HD 1.5+2.5 ReMIX.
- OpenKH Mod Manager set up for the PC version **with the mod loader (Panacea)**. The mod is a DLL that the mod
  loader starts together with the game; it cannot be patched into the game's package files, so the Mod Manager's
  "patch the game files" way of installing mods will not load it.

## Install

1. In the Mod Manager choose **Birth by Sleep** as the game.
2. *Mods > Install a New Mod > Select and install Mod Archive*, pick `BBS-KH2-Style.zip`.
3. Tick the mod, then *Mod Loader > Build and Run* (or *Build Only* and start the game yourself).

To remove it, untick it and build again.
